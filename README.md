# Fourier Series Visualization Engine 🌀

A computational mathematics project that reconstructs complex shapes using the Fourier Series and spinning epicycles.

## 📖 Overview
This project demonstrates the beauty of the **Fourier Transform** by decomposing complex shapes into a series of rotating circles (epicycles). It combines mathematical modeling, signal processing, and creative coding to generate stunning visual art.

## ✨ Features
- **Fast Fourier Transform (FFT):** Implemented from scratch for real-time frequency analysis.
- **Mathematical Modeling:** Uses Superformula, Butterfly, and Lorenz attractor curves to generate organic shapes.
- **Cinematic UI:** A futuristic HUD with live telemetry (Frequency, Amplitude, Coordinates).
- **Interactive:** Zoom, rotate, and adjust parameters in real-time.
- **Particle System:** Quantum particle trails for a deep-space aesthetic.

## 🛠️ Tech Stack
- **Python** (NumPy, Matplotlib, OpenCV) - For initial mathematical modeling and image processing.
- **JavaScript / p5.js** - For the interactive, real-time visualization engine.
- **HTML / CSS** - For the cinematic UI and certificate generation.
